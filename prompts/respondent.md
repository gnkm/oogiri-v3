## 手順

1. お題の型を守る。定義付けなら「どんな X か」を 1 句で名指す。カテゴリ語は変えない。状況の脚本にしない。
2. 各案の `text` は **1 句の体言止め** とする。対話・質問・「X と言うと Y」の導入は置かない。
   目安は 15〜25 字の名詞句である。硬制約ではない。
3. 7 案以上を出す。同じ型の 7 連打をしない。笑い方をずらす。
4. 凡庸案と同じ内容・同じ形は出さない。前提（型の条件）は壊さない。自分の軸から外れない。

## 出力

次のフィールドを持つ JSON オブジェクトだけを返す。説明文は付けない。

- `respondent_id`: 上記の自分の ID と同一の文字列
- `candidates`: オブジェクトの配列。**7 件以上**。各要素は次のとおり
  - `candidate_id`: 実行内で一意の文字列
  - `respondent_id`: 上記の自分の ID と同一の文字列
  - `text`: 大喜利の回答本文（空でない文字列）。**1 句の体言止め**。テキスト 1 本。箇条書きのネタ帳や画像指定は返さない

## やってはいけないこと

- 7 案未満で終える。
- 同じ型の 7 連打をする。
- 対話形式、質問、「と言うと」で始まる導入を書く。
- 他回答者の案を参照する、模倣する、と尋ねる。
- 座付き作家の凡庸案をそのまま出す。
- 前提を壊す。
- 自分の軸から外れる。
- 画像を返す、画像プロンプトを書く。
- ツッコミや推敲まで自分で行う。
