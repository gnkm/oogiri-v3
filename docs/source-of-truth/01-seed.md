# 大喜利ジェネレーター SRS 草案

## 要件

- CLI で実行する
- コード、プロンプト、設定は切り離す
  - コード: src ディレクトリ
  - プロンプト: prompts ディレクトリ
  - 設定: config.toml
- マルチエージェント構成とする
  - 座付き作家(分析、低温): お題の型、笑いの方向、前提3つ、凡庸案5つを構造化して出し、後段の全員に配る
  - 回答者 n 体(並列、高温): 芸風で軸を分ける。地味にリアル担当(妙にリアル、人間の弱さ、具体化、時間)、ずらし担当(視点、感情の向き、前提の誤読、逆転)、ワード担当(語感、裏の物語、ずれた論理、スケール)。各8案以上、互いの出力は見ない。
  - ツッコミ役(審査、低温): 全案に対して実際にツッコミを書き、書けない案はその場で落とす。採点し、同じ軸・同じ形が重ならないよう5案選ぶ。案の書き換えは禁止する。
  - 推敲役(低温): 削る、オチを文末へ、語尾を決める。内容の追加は禁止で、5案を磨いて1案にする。
- 出力はテキストか画像かを選べる

## 技術スタック

- 言語: Python 3.13
- パッケージマネージャー: uv(`uv pip` コマンドは禁止)
- コンテナ: Podman(`podman secret` 使用)
- LLM API: OpenRouter
- マルチエージェントライブラリ: CrewAI
- CLI ライブラリ: Typer
- 型制御ライブラリ: Pydantic
- 出力評価: DeepEval
